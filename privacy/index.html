Политика персональных данных

Если коротко: мы берём только те данные, которые вы сами оставляете в форме на сайте, используем их только для связи и работы по вашему проекту и не передаём третьим лицам.

1. Общие положения

1.1. Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сайта kri-studio.art (далее — «Сайт») и составлена в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

1.2. Оператор персональных данных: Трифонова Кристина Александровна (г. Москва), ИНН 772370935743, применяющая специальный налоговый режим «Налог на профессиональный доход», e-mail: design@kri-studio.art (далее — «Оператор»).

1.3. Направляя данные через форму Сайта, пользователь выражает согласие с настоящей Политикой.

2. Какие данные обрабатываются

  1. имя, указанное пользователем;
  2. номер телефона и/или ник в мессенджере (Telegram, WhatsApp), адрес электронной почты;
  3. сведения, которые пользователь добровольно указывает в поле «О задаче» и в переписке.

Сайт использует сервис веб-аналитики Яндекс Метрика (ООО «ЯНДЕКС», Россия) для анализа посещаемости и улучшения работы Сайта: собираются обезличенные технические данные — cookie-файлы, IP-адрес, сведения о браузере и устройстве, посещённые страницы. Эти данные не позволяют Оператору идентифицировать личность пользователя. Технические данные также могут автоматически фиксироваться хостинг-провайдером в служебных целях (обеспечение работы и безопасности Сайта). Оператор не обрабатывает специальные категории персональных данных и биометрические данные и просит не направлять их через форму Сайта.

3. Цели обработки

  1. связь с пользователем по оставленной заявке: консультация, расчёт стоимости, согласование условий работы;
  2. заключение и исполнение договора на услуги дизайна.

Оператор не осуществляет рассылок без отдельного согласия пользователя и не использует данные для целей, не указанных в настоящей Политике.

4. Правовые основания и порядок обработки

4.1. Правовыми основаниями обработки являются: согласие субъекта персональных данных (ст. 6 152-ФЗ); необходимость обработки для заключения и исполнения договора.

4.2. Обработка включает: сбор, запись, хранение, уточнение, использование, удаление и уничтожение данных.

4.3. Заявка из формы Сайта передаётся напрямую Оператору в мессенджер Telegram. Статические страницы Сайта размещены на хостинге GitHub Pages. Персональные данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Сроки хранения

Данные из заявок хранятся до достижения целей обработки, но не более 3 (трёх) лет с момента последнего взаимодействия, либо до отзыва согласия. Данные, необходимые для исполнения договора и требований налогового законодательства, хранятся в течение сроков, установленных законом.

6. Права пользователя

Пользователь вправе: получить сведения об обработке своих данных; требовать уточнения, блокирования или уничтожения данных; отозвать согласие на обработку. Для этого достаточно направить запрос на design@kri-studio.art с темой «Персональные данные». Срок ответа — не более 10 рабочих дней.

7. Cookie и локальные данные

Сайт использует cookie-файлы сервиса Яндекс Метрика для сбора обезличенной статистики посещаемости. При первом визите пользователю показывается уведомление об использовании cookie; продолжая пользоваться Сайтом, пользователь соглашается с их использованием. Отключить cookie можно в настройках браузера — это не ограничивает доступ к Сайту. Выбранная тема оформления сохраняется только в браузере пользователя (localStorage) и не передаётся Оператору.

8. Защита данных и изменения политики

8.1. Оператор принимает необходимые правовые, организационные и технические меры для защиты персональных данных.

8.2. Оператор вправе обновлять настоящую Политику. Актуальная версия постоянно доступна по адресу kri-studio.art/privacy/. Продолжение использования Сайта после публикации новой редакции означает согласие пользователя с внесёнными изменениями.
