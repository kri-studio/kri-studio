# Wave PNGs — bold (чёрная) тема

В этой папке лежат PNG-волны для темы **bold**. У неё оттенок оранжевого чуть отличается от sun, поэтому файлы отдельные.

## Схема имён

`{position}_{number}_orange.png`, где:
- **position** — `top` или `bottom`
- **number** — 1–4 для верхних волн, 5–7 для нижних

## Файлы (те же номера, что и в `/assets/img/waves/`)

- `top_1_orange.png` — над блоком контактов (перед подвалом)
- `top_2_orange.png`, `bottom_7_orange.png` — блок Кейсы (секция 2)
- `top_3_orange.png`, `bottom_5_orange.png` — блок Услуги (секция 4)
- `top_4_orange.png`, `bottom_6_orange.png` — блок Процесс (секция 6)

Цвет волны должен совпадать с `--acc` темы bold (сплошной, не градиент).
