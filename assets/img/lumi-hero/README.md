# Место для логотипа LUMI на странице /uslugi/logotip/

Загрузи сюда файл логотипа (например, `hero.webp`, `hero.png` или `hero.svg`).

После загрузки напиши мне «поставь логотип из /assets/img/lumi-hero/» —
я подставлю его в hero-блок вместо текстового плейсхолдера `LUMI`.

Рекомендации:
- Формат: webp / png / svg (лучше с прозрачным фоном)
- Размер: не менее 1200 × 960 пикс.
- Пропорции: близкие к 5:4
