# Оранжевая + чёрная

Сюда заливайте картинки в **оранжевой** и **чёрной** темах (одна папка на две темы, как договорились).

## Как заливать

1. Нажмите вверху **Add file → Upload files**.
2. Перетащите файлы в окно (можно сразу пачкой, 10–20 штук).
3. Внизу поле **Commit changes** — просто нажмите зелёную кнопку **Commit changes** (комментарий писать не обязательно).
4. Готово. Напишите мне в чате: «Залила в orange-bold, это для страницы X».

## Что писать мне после загрузки

Одной фразой: **какой проект и куда это ставить**. Например:
- «Это упаковка Корд, для кейса /kord/»
- «Это hero-фото на страницу фирменного стиля»
- «Это в галерею логотипов на /uslugi/logotip/»

Я заберу файлы из этой папки, при необходимости переконвертирую в `.webp`, положу в правильное место (`/assets/img/w/` или папку кейса) и пропишу их в HTML нужных страниц.
