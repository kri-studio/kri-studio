# Мятная

Сюда заливайте картинки в **мятной** (свежей) теме.

## Как заливать

1. Нажмите вверху **Add file → Upload files**.
2. Перетащите файлы (можно пачкой).
3. Внизу нажмите зелёную кнопку **Commit changes**.
4. Напишите мне: «Залила в mint, это для страницы X».

## Что писать мне после загрузки

Одной фразой — какой проект и куда. Например:
- «Это для кейса Веда»
- «Это на страницу /uslugi/dizayn-sayta/ в примеры сайтов»

Я переконвертирую в `.webp` при необходимости и пропишу в HTML.
