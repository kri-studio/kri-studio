# Розовая

Сюда заливайте картинки в **розовой** теме.

## Как заливать

1. Нажмите вверху **Add file → Upload files**.
2. Перетащите файлы (можно пачкой).
3. Внизу нажмите зелёную кнопку **Commit changes**.
4. Напишите мне: «Залила в rose, это для страницы X».

## Что писать мне после загрузки

Одной фразой — какой проект и куда ставить. Например:
- «Это оформление соцсетей для Bloom, в кейс /bloom/»
- «Это на страницу /uslugi/firmennyy-stil/ в галерею работ»

Я заберу, при необходимости переконвертирую в `.webp` и пропишу в HTML.

## Названия файлов

Латиницей удобнее (`bloom_social_01.jpg`), но не обязательно — переименую сама.
